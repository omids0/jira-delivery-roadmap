# نقشه راه تحویل Jira

نقشه‌ی راه تحویل برای **هر پروژه‌ی Jira** (Data Center / Server): کوتاه‌ترین مسیر برای بستن استوری‌های باز، با توجه به وابستگی‌ها و ظرفیت تیم بک‌اند و فرانت. مسیر بحرانی، خط زمانی هر نفر و اسپرینت پیشنهادی بعدی.

> **وضعیت: v0.3 — نقشه‌ی راه کامل.** KPI و what-if، نقشه‌ی کلی پروژه، سرعت واقعی تیم (از اسپرینت‌های بسته‌شده)، فلوچارت وابستگی، خط زمانی نفرات با مسیر بحرانی، تخصیص اپیک به نفرات، کارهای باز هر نفر، جدول تحویل اپیک‌ها، اسپرینت پیشنهادی و جدول کامل زمان‌بندی. همه‌چیز زنده از Jira خوانده می‌شود. ساختار: [docs/DESIGN.md](docs/DESIGN.md).

## چطور کار می‌کند

مثل ریپوی خواهر [`jira-status-dashboard`](https://github.com/omids0/jira-status-dashboard): Jira هدر CORS نمی‌فرستد، پس برنامه تو **خود صفحه‌ی Jira** اجرا می‌شود (با بوکمارک) و از لاگین فعلی کاربر استفاده می‌کند. بدون توکن، بدون سرور، بدون IT. پروژه را از سلکت‌باکس بالا انتخاب می‌کنی و همه‌چیز زنده از Jira خوانده می‌شود. هیچ دیتای شرکتی داخل ریپو نیست.

## نصب (برای هر همکار)

**یک‌بار برای صاحب ریپو:** Settings → Pages → **Source: GitHub Actions**. بعد از هر push روی `main` سایت خودکار منتشر می‌شود (روی پلن رایگان فقط برای ریپوی public).

1. صفحه‌ی `https://omids0.github.io/jira-delivery-roadmap/` را باز کن و دکمه‌ی «نقشه راه Jira» را بنداز روی نوار بوکمارک (`Ctrl+Shift+B` برای نمایش نوار).
2. وارد Jira شو، روی بوکمارک بزن، پروژه را از سلکت‌باکس انتخاب کن. `Esc` یا «بستن» برمی‌گرداند.

**برای شرکت دیگر:** ریپو را fork کن و Pages خودت را روشن کن؛ صفحه‌ی نصب فورک، بوکمارکی می‌سازد که اسکریپت را از همان فورک می‌خواند.

**امنیت:** بوکمارک یک اسکریپت از سایت Pages را داخل صفحه‌ی Jira اجرا می‌کند، پس آن اسکریپت به سشن Jira کاربر دسترسی دارد. فقط به ریپویی وصل شو که به آن اعتماد داری (یا fork خودت). هیچ دیتایی به جایی فرستاده نمی‌شود.

**محدودیت:** اگر Jira با CSP سخت‌گیرانه جلوی اسکریپت خارجی را بگیرد، بوکمارک کار نمی‌کند.

## کانفیگ هر پروژه — `config/projects.json`

بدون کانفیگ هم هر پروژه‌ای باز می‌شود. برای نتیجه‌ی دقیق‌تر، `defaults` برای همه‌ی پروژه‌ها و `projects.<KEY>` برای override:

```json
{
  "defaults": {
    "components": { "be": "Back-End", "fe": "Front-End" },
    "labels": { "be": ["backend"], "fe": ["frontend"] },
    "issueTypes": { "story": ["Story"] },
    "blockLinkPattern": "block",
    "weekend": [4, 5],
    "locale": "fa-IR-u-ca-persian",
    "team": { "be": 1, "fe": 1 },
    "parallelStories": 3
  },
  "projects": {
    "ABC": { "components": { "fe": "UI" }, "team": { "be": 2, "fe": 2 } }
  }
}
```

آبجکت‌ها کلید به کلید ادغام می‌شوند؛ آرایه و مقدار ساده جایگزین می‌شوند.

## توسعه

```bash
# Node 20+
npm install
npm test               # تست‌های واحد
npm run build:site     # خروجی در site/ (roadmap.js + index.html)
```

برای امتحان محلی: `site/` را با هر سرور static بالا بیاور (مثلاً `npx serve site`)، صفحه‌ی نصب را باز کن و بوکمارک را بساز. چون `localhost` صفحه‌ی Jira نیست، برای تست مستقیم می‌توانی محتوای `site/roadmap.js` را تو Console صفحه‌ی Jira paste کنی.

ساختار و قدم‌های بعدی: [docs/DESIGN.md](docs/DESIGN.md).
